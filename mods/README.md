# Claude Code mods

这里收录可独立安装的 Claude Code function-hooks mods，不需要 CPA、ChatGPT 或 GLM 订阅，也不由根目录 `install.sh` 安装。

| Mod | 版本 | 功能与安装 |
|---|---|---|
| token-speed | 0.2.1 | 主控与活跃子代理的输出速率；见 [token-speed README](token-speed/README.md) |

安装前请查看各 mod 的 CLI 兼容版本、安装前提与限制。Marketplace 名称为 `claude-workflow-mods`；本次发布内容合并到 `main` 后可使用 marketplace 安装，合并前使用插件 README 中的发布版本加载方式。

每个 mod 独立维护版本；版本与 tag 规则见 [VERSIONING.md](VERSIONING.md)，token-speed 的历史见 [CHANGELOG.md](token-speed/CHANGELOG.md)。
